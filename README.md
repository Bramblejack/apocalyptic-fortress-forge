# Apocalyptic Fortress (unofficial Forge 1.20.1 port)

Fortress overhaul mod: replaces the Nether fortress with a huge one.

**Original mod and all original content: [hexnowloading](https://www.curseforge.com/minecraft/mc-mods/apocalyptic-fortress)
(CurseForge project 700741, source: https://github.com/hexnowloading/apocalyptic-fortress).**
This repository is an **unofficial** port of version 0.0.4 of the Minecraft 1.19.3 Forge version to
Minecraft 1.20.1 (Forge 47.4.28). It is not affiliated with or endorsed by the original author.
